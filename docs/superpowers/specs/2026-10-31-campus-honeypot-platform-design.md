# 校园低交互蜜罐攻击行为分析与可视化平台设计规格

## 1. 项目目标

构建一个面向校园网络安全教学与毕业答辩的本地 Web 平台，使用脱敏模拟蜜罐日志完成“日志导入/回放—标准化—规则检测—攻击事件—告警处置—可视化分析—报告导出”的完整闭环。

系统默认只处理本地模拟数据，不连接公网蜜罐，不执行攻击载荷，不抓取真实校园网络流量。

## 2. 视觉方向

采用蓝白科技风：深蓝渐变背景、冷白内容面板、青蓝高亮、细网格与扫描线背景，使用轻量玻璃质感和状态动效。红、橙、绿色仅用于严重级别表达。页面在 1440×900 桌面尺寸下优先优化，同时保持平板和窄屏可读。

## 3. 技术架构

- 后端：Python 3、Flask
- 数据库：SQLite，使用参数化 SQL；数据访问层保持可替换
- 前端：Jinja 模板、原生 JavaScript、CSS、ECharts
- 输入格式：JSON、JSONL、CSV
- 输出格式：CSV、可打印 HTML
- 运行方式：本地开发服务器，默认绑定 127.0.0.1

系统采用 Flask 单体结构。页面请求由 Flask 路由返回，图表和筛选通过 REST 接口获取数据。规则检测、统计聚合和导出逻辑放在独立服务模块中，避免与模板耦合。

## 4. 页面与功能

### 4.1 登录页

提供演示账号登录、错误提示和会话保护。首版使用本地演示账号，不保存明文密码。

### 4.2 总览页

展示攻击总数、高危告警、独立来源 IP、节点状态；提供攻击趋势、攻击类型分布、风险等级分布、来源排行、最近事件。图表点击后可跳转到事件中心并携带筛选条件。

### 4.3 事件中心

支持按时间范围、来源 IP、协议、服务、攻击类型、严重级别和节点筛选；提供分页、空状态、错误状态和事件详情抽屉。详情展示命中规则、脱敏字段、证据摘要和关联告警。

### 4.4 行为分析

按来源 IP 下钻，显示攻击时间线、攻击类型组合、目标服务/端口、风险变化和事件数量。支持从总览排行或事件详情进入。

### 4.5 告警中心

展示待处理、已确认、已关闭告警。支持按严重级别和状态筛选，查看证据、确认告警、关闭告警和填写处置备注。所有状态变化写入审计日志。

### 4.6 日志回放

支持选择预置场景或导入样例日志，提供开始、暂停、重置和 1x/2x/5x 倍速。回放过程按事件时间顺序写入分析链路，并实时刷新总览和事件列表。

### 4.7 节点管理

展示模拟 SSH、HTTP 等低交互节点的协议、端口、状态、位置和事件数。启停只改变演示状态，不启动公网监听。

### 4.8 规则管理

展示规则名称、攻击类型、阈值、时间窗、严重级别和启用状态。首版规则包括：SSH 暴力破解、端口扫描、Web 路径探测、敏感文件探测、高频访问、多类连续行为。

### 4.9 报告页面

按时间范围生成汇总，展示事件数、告警数、攻击类型和来源排行；支持导出 CSV 与打印版 HTML。

## 5. 数据模型

- `users`：用户、角色、密码哈希、创建时间
- `honeypots`：节点名称、协议、端口、状态、位置
- `raw_logs`：原始日志的标准化字段、来源 IP、目标端口、协议、路径、动作、脱敏 JSON
- `attack_events`：关联原始日志、规则、类型、严重级别、置信度、来源 IP、证据摘要、状态
- `rules`：规则名称、类型、阈值、时间窗、严重级别、启用状态
- `alerts`：关联事件、状态、确认人、创建时间、处置备注
- `audit_logs`：用户、动作、目标、时间

## 6. 日志处理与规则

导入流程为：文件大小和字段长度校验 → JSON/CSV 解析 → 字段标准化 → 脱敏与重复识别 → 保存原始日志 → 按时间窗口检测 → 合并攻击事件 → 生成告警。

示例规则：

- 同一来源 IP 5 分钟内 SSH 登录失败不少于 5 次，识别为暴力破解。
- 同一来源 IP 60 秒内访问不少于 5 个不同目标端口，识别为端口扫描。
- 短时间访问多个常见管理或不存在路径，识别为 Web 路径探测。
- 请求路径包含 `.env`、`config`、`backup` 等特征，识别为敏感文件探测。
- 单 IP 单位时间事件数超过阈值，识别为高频访问。
- 同一 IP 在短时间内触发两类以上规则，生成关联行为事件。

## 7. 安全与错误处理

系统只绑定 127.0.0.1；不执行输入内容，不访问真实文件，不下载外部载荷；用户可控文本全部 HTML 转义；数据库查询使用参数化方式；导入限制文件大小、行数和字段长度；空数据、格式错误、规则异常和导出失败均显示可读提示。

## 8. 验收标准

- 能导入不少于 100 条 JSONL/CSV 样例日志。
- 至少正确识别 SSH 暴力破解、端口扫描、Web 路径探测三类行为。
- 图表、统计卡片和事件列表在同一筛选条件下数量一致。
- 回放支持开始、暂停、重置和倍速。
- 告警支持确认、关闭和备注。
- 能查看单个来源 IP 的行为时间线。
- 能导出 CSV 和可打印 HTML 报告。
- 演示数据规模下主要页面响应目标不超过 2 秒。

## 9. 实现边界

第一阶段实现完整本地演示闭环与核心页面；真实 SSH/HTTP 监听、GeoIP、外部威胁情报和多节点部署不纳入首版必需范围，避免扩大安全边界和部署复杂度。
